# Практична робота №1
**Тема:** Розробка PHP-структур та вивід результатів у вебсторінку  
**Студент(ка):** Руслана Савченко  
**Варіант:** №8 — Система бронювання (готель/зали)  

---

## 🎯 Мета роботи
Ознайомитися з базовим синтаксисом мови програмування PHP (змінні, типи даних, асоціативні масиви, умовні конструкції, цикли та функції), навчитися поєднувати PHP-код із HTML-розміткою і виводити результат роботи скрипта у вигляді стилізованої вебсторінки в браузері.

---

## 📋 Завдання варіанта №8
* **Дані:** Масив номерів/залів (`number`, `capacity`, `pricePerNight`, `isBooked`).
* **Умова:** Якщо `isBooked` має значення `true` — виводиться статус «Заброньовано», інакше — «Вільний».
* **Агрегатний показник:** Обчислення сумарного очікуваного доходу від заброньованих номерів.

---

## 📁 Структура проєкту
* `index.php` — головний PHP-скрипт із даними, обчисленнями та HTML-структурою.
* `style.css` — CSS-стилі (пастельно-рожевий дизайн, сітка CSS Grid, адаптивність).
* `README.md` — звіт про виконання роботи та документація.

---

## 🛠 Опис виконання роботи
1. **Налаштування середовища:** Увімкнено виведення помилок PHP (`error_reporting(E_ALL)`) для зручності розробки.
2. **Оголошення даних:** Створено асоціативний масив `$rooms`, що містить 5 номерів із полями `number`, `capacity`, `pricePerNight` та `isBooked`.
3. **Функція форматування:** Написано типізовану функцію `formatRoom(array $room): string`, яка формує короткий опис (кількість місць та ціну за ніч).
4. **Умовна логіка:** За допомогою тернарного оператора `?:` реалізовано динамічну зміну текстового статусу («Заброньовано» / «Вільний») та відповідних CSS-класів (`booked` / `free`).
5. **Обчислення агрегату:** За допомогою циклу `foreach` пораховано загальну суму очікуваного доходу лише від заброньованих номерів.
6. **Інтерфейс:** Реалізовано сучасну двоколонкову верстку в пастельно-рожевій гамі без дублювання інформації та з фіксованими заголовками номерів.
