## 🎯 Мета роботи
Навчитися обробляти дані HTML-форм у PHP через суперглобальні масиви $_GET і $_POST; освоїти серверну валідацію введених даних (обов'язковість, тип, діапазон, формат) і повторне відображення форми з повідомленнями про помилки; додати клієнтську валідацію засобами HTML5 та JavaScript; навчитися зберігати й відновлювати стан інтерфейсу за допомогою localStorage/sessionStorage браузера.
___

## 📋 Завдання варіанта №8
* **Поля форми:** 
  * `guestName` — ім'я та прізвище гостя (текст);
  * `roomNumber` — номер кімнати (число);
  * `checkIn` — дата заїзду (дата);
  * `checkOut` — дата виїзду (дата).
* **Правила валідації:**
  * Дата виїзду обов'язково має бути пізнішою за дату заїзду;
  * Ім'я гостя повинно містити лише літери та пробіли (перевірка за допомогою `preg_match` у PHP та регулярних виразів у JS).
* **Сценарій localStorage:** Запам'ятовувати останні обрані дати заїзду й виїзду для наступного бронювання.

### Крок 2. Створення HTML-форми
У файлі `form.php` додано тег `<form method="post" action="form.php">`. Для полів вводу встановлено відповідні типи та атрибути HTML5-валідації:
* `guestName`: `type="text"`, `required`, `pattern="^[\p{L}\s]+$"`;
* `roomNumber`: `type="number"`, `min="1"`, `required`;
* `checkIn` та `checkOut`: `type="date"`, `required`.

---

### Крок 3. Реалізація серверної обробки й валідації (PHP)
На початку файла перевіряється метод відправки `$_SERVER['REQUEST_METHOD'] === 'POST'`. За допомогою `preg_match('/^[\p{L}\s]+$/u', $guestName)` перевіряється коректність імені (лише літери та пробіли). Дати обробляються через `strtotime()` для перевірки умови, що дата виїзду є пізнішою за дату заїзду. У разі виявлення помилок сформований масив `$errors` передається для відображення на сторінці.

### Крок 6. Реалізація сценарію localStorage
На JavaScript реалізовано збереження дат заїзду та виїзду при їх зміні користувачем:
```javascript
checkInInput.addEventListener('change', () => {
    localStorage.setItem('savedCheckIn', checkInInput.value);
});
checkOutInput.addEventListener('change', () => {
    localStorage.setItem('savedCheckOut', checkOutInput.value);
});
```
